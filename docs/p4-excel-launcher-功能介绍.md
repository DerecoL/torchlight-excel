# P4 Excel 启动器功能介绍

P4 Excel 启动器是一款面向策划日常配表工作的桌面工具。它把 P4 工作区切换、Excel 文件收藏、同步打开、快速改表和批量自动配表集中到一个界面中，减少在 P4V、文件目录和 Excel 之间来回查找与操作的成本。

## 产品定位

工具主要服务于三类高频场景：

- 快速找到并打开常用配置表
- 修改已有 Excel 配置时自动完成 P4 同步与 checkout
- 按模板批量生成或更新多张关联配置表

它不是替代 Excel 或 P4V，而是把策划最常用、最容易重复出错的操作收拢成更短的工作流。

## 核心功能

### P4 工作区管理

工具会读取当前账号可用的 P4 工作区，并在顶部下拉框中展示。用户可以直接切换工作区，工具会同步使用对应的 Stream。

常用工作区可以收藏，收藏后会优先展示，适合经常在多个分支或多个项目工作区之间切换的用户。

### Excel 收藏夹

用户可以把常用 Excel 表按业务分组收藏，例如怪物配置、关卡配置、任务配置等。每个分组下可以维护多个表格，并为文件设置更容易识别的别名。

文件支持手动输入相对路径，也支持从本地选择文件并反查 P4 路径。分组和文件收藏支持导入、导出与排序，方便团队内共享常用表集合。

### 同步并打开

打开表格前，工具会先执行 P4 同步，确保本地文件是最新版本。

文件卡片提供两种打开方式：

- 仅查看：同步后直接打开，不 checkout，适合查表。
- Checkout 并打开：同步后 checkout，再打开 Excel，适合编辑。

这能减少直接打开旧文件、忘记 checkout、或误改只读文件的情况。

### 按 ID 快速修改

快速修改功能适合修改某张表中的一行已有数据。用户填写 Sheet、表头行、主键列和主键值后，工具会读取目标行并展示可编辑字段。

修改后可以先预览字段差异，再确认写入。写入时工具会自动 checkout，并在本地生成备份，方便提交前复核或回退。

### 自动配表模板

自动配表用于把一套业务输入批量写入一张或多张 Excel 表。模板中可以定义输入字段、ID 生成规则、目标 Excel、Sheet、主键列和字段映射。

模板支持可视化编辑，也支持直接编辑 JSON。对于复杂规则，可以通过 JSON 精细控制。

模板能力包括：

- 输入字段：定义执行时需要填写的业务参数
- ID 序列：为新增行自动生成连续 ID
- 条件行规则：根据输入条件决定是否生成某行
- 多表写入：一次写入多张关联 Excel
- 引用字段：子表或主表之间可以引用本次生成的 ID
- 拼接字段：把多个值按分隔符拼成一个单元格内容

### 批量执行与预览

自动配表支持一次填写多行业务数据，并批量生成预览。预览会展示每一行输入对应的新增、更新、目标文件、Sheet、行号和字段变化。

用户确认预览后再执行写入。写入阶段会自动完成 P4 sync、checkout、备份和 Excel 写入。预览有错误时不会写入，避免模板配置或输入数据异常直接影响正式表。

## 典型使用场景

### 日常查表

策划可以把常用表加入收藏夹，通过分组快速定位文件。需要查看时点击“仅查看”，工具自动同步最新版并打开 Excel。

### 单行改表

当只需要修改某个 ID 对应的少数字段时，可以使用“快速修改”。相比手动查找行号、修改字段、确认差异，这个流程更短，也更容易复核。

### 多表关联新增

例如新增一个 NPC，同时需要写入 NPC 主表、属性表、技能表和小地图图标表。自动配表模板可以把这些关联写入一次性生成，并自动处理新 ID 与表间引用。

### 模板化批量配置

对于结构固定、重复性高的配置任务，可以先沉淀为模板。后续只需要填写业务数据，即可批量生成 Excel 变更，减少重复填表和漏填字段。

## 产品价值

- 降低找表成本：常用表集中收藏和分组管理。
- 降低 P4 操作成本：打开、同步、checkout 统一入口完成。
- 降低改表风险：写入前有预览，写入时有备份。
- 提升批量配置效率：用模板替代重复手工填表。
- 支持团队复用：收藏分组和自动配表模板都可以导入导出。

## 适用边界

工具适合处理策划常见的 Excel 配置管理与批量生成工作。对于需要大量人工判断、复杂 Excel 公式维护、或非 `.xlsx` 文件编辑的场景，仍建议回到 Excel 和 P4V 中处理。
