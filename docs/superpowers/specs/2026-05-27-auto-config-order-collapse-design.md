# 自动配表表/行顺序与折叠设计

## 背景

自动配表的生成顺序由模板 JSON 中 `tables` 数组顺序和每张表内 `rows` 数组顺序决定。用户需要在可视化界面中直接调整表和行规则顺序，以便让被引用的表或行先生成。同时，当表和行规则都展开时页面过长，需要能够临时收起配置块。

## 目标

1. 可视化模板编辑器中，每张目标表支持上移、下移。
2. 每张目标表支持收起和展开。
3. 每条行规则支持上移、下移。
4. 每条行规则支持收起和展开。
5. 排序会同步影响模板 JSON，因此预览和执行按界面排序后的顺序生成。
6. 折叠状态只影响界面显示，不写入模板 JSON。

## 交互规则

- 表卡片标题栏展示 `key / sheetName / relativePath`。
- 行规则标题栏展示 row key。
- 第一张表点击上移不改变顺序。
- 最后一张表点击下移不改变顺序。
- 第一条行规则点击上移不改变顺序。
- 最后一条行规则点击下移不改变顺序。
- 点击收起后隐藏配置详情，只保留标题栏。
- 再次点击展开后恢复显示配置详情。
- 从 JSON 重新渲染可视化界面时，默认全部展开。

## 非目标

本次不把折叠状态保存到模板配置。

本次不新增拖拽排序。
