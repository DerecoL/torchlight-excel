# P4 Excel 启动器使用指南

这是一款给策划使用的 Excel 表格管理工具。它可以按 P4 工作区管理常用表格，打开前自动同步最新版，也支持按 ID 快速修改已有行，以及用模板批量生成配置。

## 使用前准备

请先确认本机已经具备以下环境：

- 已安装 P4 命令行工具，并能在命令行执行 `p4`
- 已配置可用的 P4 账号和工作区
- 需要打开的 Excel 表格已在对应 P4 工作区中

## 首次配置

1. 启动应用后，点击右上角「设置」。
2. 填写或自动检测 P4 信息：
   - `P4 Server`：P4 服务器地址
   - `用户名`：P4 登录账号
   - `默认工作区`：可先留空，之后在顶部下拉框选择
   - `Depot 路径前缀`：Streams 所在仓库根路径
3. 点击「测试连接」确认可连接。
4. 点击「保存并连接」。

连接成功后，顶部会显示当前账号和工作区。

## 管理工作区

- 在顶部「工作区」下拉框选择要使用的工作区。
- 点击星标可以收藏常用工作区，收藏后会显示在「常用」分组。
- 切换工作区后，工具会使用该工作区对应的 Stream。
- 如果列表不完整，点击刷新按钮重新读取。

## 管理常用 Excel

1. 点击左侧「收藏分组」旁的 `+`，新建一个分组，例如「怪物配置」。
2. 选中分组后，点击「添加文件」。
3. 添加方式二选一：
   - 手动输入相对路径，例如 `design/demo_table/npc.xlsx`
   - 浏览本地文件，让工具自动反查 P4 路径
4. 可填写显示别名，便于识别。

文件加入收藏后，可以直接在卡片上操作：

- 「仅查看」：同步最新版后打开，不 checkout。
- 「Checkout 并打开」：同步最新版，执行 checkout，然后打开 Excel。
- 「快速修改」：按主键 ID 读取并修改已有行。

分组支持重命名、删除、导入和导出。文件也支持拖拽排序。

## 按 ID 快速修改

适合只改某张表里的一行已有数据。

1. 在文件卡片上点击「快速修改」。
2. 确认 Sheet、表头行、主键列，默认通常是：
   - Sheet：`data`
   - 表头行：`2`
   - 主键列：`id`
3. 输入要修改的主键值，点击「读取行」。
4. 在字段列表中修改需要变更的值。
5. 点击「预览变更」，确认只改了预期字段。
6. 点击「确认写入」。

写入时工具会 checkout 文件，并在本地生成备份。提交前请在 P4V 中再次审核变更。

## 自动配表

适合一次写入多张表、生成新 ID、或根据模板批量新增配置。

### 1. 进入工作台

点击右上角「自动配表」，进入自动配表工作台。

### 2. 准备模板

在「模板管理」中可以：

- 新建模板
- 导入模板 JSON
- 导出模板 JSON
- 用可视化面板编辑输入字段、ID 序列、目标表和行规则
- 在 JSON 面板中做精细调整

模板主要定义三类内容：

- 输入字段：执行时需要填写哪些业务参数
- ID 序列：哪些字段需要自动生成 ID
- 目标表与行规则：写入哪些 Excel、哪个 Sheet、哪些列

常用字段规则：

- `input`：使用界面输入值
- `id`：自动生成新 ID
- `inputOrId`：有输入值就用输入值，留空则自动生成 ID
- `ref`：引用本次生成的其他行字段
- `join`：把多个值拼成一个字符串，例如用 `|` 连接多个技能 ID

### 3. 执行配表

1. 切换到「执行配表」。
2. 选择模板。
3. 在「数据行」中填写业务数据；需要多条配置时点击「新增行」。
4. 如需指定 ID 起始值，可在「ID 起始值」中填写；不填时工具会尝试从已有表格最大 ID 后顺延。
5. 点击「生成预览」。
6. 检查预览中的新增、更新、行号和字段差异。
7. 确认无误后点击「确认写入」。

写入前必须先看预览。预览有错误时不会写入。

## 常见问题

### 找不到工作区

先检查 P4 设置是否正确，再点击顶部刷新按钮。如果仍然没有结果，确认该账号是否有已绑定 Stream 的工作区。

### 打开失败或同步失败

通常是 P4 连接、权限、路径或文件占用问题。先确认 P4V 中同一路径是否能正常 sync 和 checkout。

### 快速修改找不到行

检查 Sheet、表头行、主键列和主键值是否正确。快速修改只修改已有行，不会新增行。

### 自动配表没有生成变更

重点检查三处：

- 模板是否配置了目标表和行规则
- 行规则条件是否命中当前输入
- 字段映射是否写到了真实存在的 Excel 表头

### 自动 ID 失败

如果工具无法从已有表格推断最大 ID，需要手动填写对应 ID 序列的起始值。

## 推荐使用习惯

- 普通查看用「仅查看」，需要编辑再用「Checkout 并打开」。
- 写入前一定先看预览，确认文件、Sheet、行号和字段变化。
- 自动配表模板建议先在测试表验证，再用于正式表。
- 写入后先在 P4V 或 Excel 中复核，再提交。
